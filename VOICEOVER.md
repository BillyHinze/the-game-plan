# Record the narration yourself
The default video is 2 minutes 10 seconds. Read the original script in `src/data/narration.ts` or the delivered `narration.txt`.
Use the timed `READ-THIS-TO-RECORD.txt` guide to line up the ten paragraphs. The delivered film contains original effects and a quiet instrumental bed, without a generated voice.
Upload `public/audio/voiceover.mp3` through GitHub, then use Actions → Render The Game Plan → Run workflow → voiceover=yes. Or add your take in your preferred video editor.
Choose captions=false in the workflow for a clean version to caption yourself.
